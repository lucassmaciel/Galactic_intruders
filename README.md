# Galactic Intruders

Jogo de arcade em Python com Pygame. Hordas de mísseis caem sobre a base. Mova a nave para interceptá-los antes que a vida da base chegue a zero. Cada míssil destruído vale pontos, e as explosões têm animação e som.

## Arquivos

- `main.py`: o jogo inteiro (nave, base, mísseis, hordas e explosões).
- `assets/explosion.wav`: som de explosão.

## Como rodar

```bash
pip install pygame
python main.py
```

Controles: setas para mover a nave.
